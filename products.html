製品・ソリューション

主業務である共用チェックインシステムを中心に、共用セルフサービス、空港の情報管理、旅客案内、搭乗券検証、保安検査、チェックインカウンター、搭乗口業務、端末のリモート運用を支えるソリューションを提供しています。掲載画面には開発用のデモデータを使用しています。

主力ソリューションCommon-use Check-in System

共用チェックインシステム

複数の航空会社がチェックインカウンターの端末・周辺機器を共用できる環境を、空港の規模、就航航空会社、既存設備、実際の運用に合わせて設計・構築します。

CUTE・CUPPSと同等の共用チェックイン環境として、ハードウェア、ソフトウェア、航空会社DCS・アプリケーションとの接続、導入後の運用サポートまでを一体で提供します。

  • チェックイン端末、モニター、ネットワーク機器の選定・調達
  • 搭乗券・手荷物タグプリンター、BGR、OCR／MSR等の周辺機器連携
  • 航空会社DCS・チェックインアプリケーションの設定と接続試験
  • 航空会社選択・ログインと利用セッションの管理
  • 航空会社・端末・カウンター別の利用状況、異常終了の可視化
  • 利用実績のバックアップ・CSV出力
  • 国内外の航空会社IT部門との技術調整、導入・切替支援
  • 運用開始後のリモート支援、障害切り分け、保守・機能改善

CUSS 1.5対応・CUSS 2移行準備Common Use Self Service

Airport Solutions CUSS Platform

IATAではCUSS 2への移行が進められ、CUSS 1.xに対する新たな機能追加や標準更新は終了する方向にあります。一方、現在も多くの空港・航空会社でCUSS 1.5環境が運用されており、認証環境や航空会社アプリケーションを含め、移行には一定の期間が必要です。

Airport Solutionsでは、自社開発によるCUSS 1.5対応プラットフォームを通じて、既存環境の安定運用と保守を当面の間継続します。そのうえで、空港設備、航空会社アプリケーション、更新計画を踏まえ、お客様にとって最適なタイミングでCUSS 2への移行を支援します。

既存環境を急いで置き換えるのではなく、運用を止めずに次世代標準へつなぎます。

  • CUSS 1.5対応プラットフォーム
  • 既存航空会社アプリケーションとの互換性検証
  • CUSS 1.5環境の運用・保守支援
  • CUSS 2対応に向けた事前評価と移行計画
  • 空港・航空会社ごとの段階的な切替支援
  • CUSS Technical Specificationに準拠したアプリケーション開発
  • 自社開発による継続的な機能改修

IATAが公表するCUSS 2移行計画と現行環境の状況を踏まえ、段階的な移行をご提案します。 IATA CUSS 2 Migration Plan

アプリケーション自社開発対応CUSS Application Development

CUSS上で動作するアプリケーションも開発

プラットフォームの提供に加え、CUSS Technical Specificationに準拠した航空会社向けセルフサービスアプリケーションや、CUSS上で動作する業務・運用・検証アプリケーションの設計・開発にも対応します。

チェックイン業務画面からPassport／OCR、Barcode Reader、Magnetic Card Reader、ATB・BTPプリンター等のCUSS周辺機器連携まで、航空会社・空港の個別要件に合わせて実装できます。

  • 航空会社向けチェックイン・旅客案内アプリケーション
  • CUSSの起動・終了、リソース取得・解放を考慮した設計
  • Passport／OCR、BGR、MSR、ATB・BTP等とのデバイス連携
  • 周辺機器の状態確認、印字、読取を行う検証ツール
  • 既存アプリケーションの移行・互換性確認・機能改修

掲載画面はCUSS連携を確認するためのローカル開発・検証用アプリケーションであり、実在する航空会社または旅客のデータは使用していません。

プロトタイプ稼働・機能検証中Gate Operations

Local Boarding Application

HOST／DCSに接続しない環境でも、搭乗券の読取、搭乗人数の集計、搭乗履歴の確認をローカルで行える搭乗口業務アプリケーションです。便ごとの搭乗状況と座席分布を一つの画面で把握できます。

チャーター便・臨時便など、常設の搭乗システムを用意しにくい限定運用に最適です。

  • BCBP搭乗券の読取と搭乗受付
  • 搭乗予定・搭乗済み・未搭乗人数のリアルタイム集計
  • 最大4台のBGRとUSBキーボード型スキャナーに対応
  • クラス別・搭乗状況別のダイナミックシートチャート
  • 搭乗履歴、判定フロー、DEBOARD処理の確認

プロトタイプ稼働・解析検証中Boarding Pass Analysis

BCBP Inspector

航空会社の搭乗券データを読み取り、IATA Passenger Services Conference Resolution 792に基づくBCBPの構造と各フィールドを瞬時に解析・可視化する、空港事業者様向けの検証ツールです。

判定結果だけでなく、該当項目、フィールド定義、期待される文字種・桁数、入力値、エラー理由などの詳細な判定根拠までアプリ内に表示。日常的な解析ではIATA Resolution本文を別途参照する必要がありません。

  • BCBP RAWデータの即時解析
  • Resolution 792 Matrixによる項目別表示
  • 必須項目・条件項目・文字位置の可視化
  • 不正な文字種やフィールド値の強調表示
  • 判定根拠・フィールド解説・Notesをアプリ内に表示
  • BGRからの読取、JSON・Matrix PDF出力

プロトタイプ稼働Airport Operations Database

AODB

定期便・季節便・各日運航状況を一元管理し、FIDSや旅客処理システムへ便情報を供給します。地方空港や少人数の体制でも管理しやすく、大規模なサーバー設備を前提としないシンプルな構成です。

  • 定期便・季節便・各日運航状況の管理
  • 運航時刻、搭乗口、手荷物受取、ステータスの更新
  • 空港・航空会社・設備マスターの管理
  • APIによるFIDS・関連製品との連携

AODBを中心とした空港運航情報連携イメージ

AODB連動検証中Flight Information Display System

FIDS

AODBで管理する便情報を利用し、出発便・到着便・搭乗口・手荷物受取の各画面へ分かりやすく表示します。空港の表示設備に合わせた画面構成と多言語表示に対応します。

  • 出発便・到着便の一覧表示
  • 搭乗口と手荷物受取の専用表示
  • 運航時刻・変更時刻・ステータスの反映
  • AODB APIによる自動更新

基礎開発中Passenger Processing

Passenger Reconciliation System

搭乗券のBCBPとAODBの運航情報を照合し、保安検査場への入場可否を判定します。判定結果を現場スタッフと旅客に明確に表示し、Supervisor画面から便別の状況を確認できます。

  • BCBP読取とAODBによる便照合
  • 入場可能時間帯、重複読取などの判定
  • 便別・端末別のリアルタイム状況確認
  • 判定履歴と運用上書きの管理

Access BGRと係員端末による保安検査場運用イメージ

開発・検証中Centralized Terminal Operations

Terminal Support

空港外のリモートサポート拠点から、空港内の共用チェックイン端末や業務端末を中央監視・管理し、日々発生する航空会社ソフトウェアの更新、ログ収集、状態確認、障害調査、ファイル配信、遠隔操作をタイムリーに行うための統合サポート基盤です。

現地作業だけに頼らず、各端末の状況を把握しながら、必要な更新・調査・復旧支援を迅速に実施できます。

  • 端末のオンライン・警告・オフライン・時刻ずれを中央監視
  • Live Screenと遠隔操作による状況確認・操作支援
  • 航空会社ソフトウェア、設定ファイル、更新データの配信
  • アプリケーション・サービスの起動停止、再起動等のリモート操作
  • 端末登録、Provisioning、時刻同期、アラート管理
  • 配信結果、操作履歴、監査ログによる追跡と調査
